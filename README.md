# Bài tập buổi 3 – React Native

Ứng dụng thực hành ngày 29/09/2026, sử dụng React Native và Expo.

## Chức năng

- Screen 1 hiển thị 6 ô màu theo bố cục mẫu.
- Nhập UserName và MSSV.
- Kiểm tra dữ liệu không được để trống hoặc chỉ chứa dấu cách.
- Nhấn "Click me" để sang Screen 2 và hiển thị thông tin đã nhập.
- Nhấn mũi tên ở góc trên trái để quay lại Screen 1.

## Cách chạy

1. Cài các thư viện: `npm install`
2. Khởi động Expo: `npx expo start`
3. Mở ứng dụng bằng Expo Go hoặc máy ảo Android.

## Công nghệ

- React Native
- Expo
- React Hooks
- react-native-safe-area-context
